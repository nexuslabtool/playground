# おわり時間

開始時刻、予定ごとの所要時間、予定の後に取る休憩を入力して、全部終わる時刻と予定表を計算する無料のミニツールです。

## こんなときに

- 午前中の作業が昼休みまでに終わるか確認する
- 勉強と休憩を順番に並べる
- 会議や作業の段取りを考える

## 使い方

1. `owari-jikan/index.html` を保存し、ブラウザーで開きます。インストールや登録は不要です。
2. 開始時刻、予定名、所要時間、後の休憩を入力します。
3. 終了時刻と予定表が自動で更新されます。必要ならテキストでコピーして残せます。

最初の入力はサンプルです。「入力をクリア」で消せます。HTMLファイルを保存すればオフラインでも使えます。

## 計算の範囲

- 予定は上から順番に実行する想定です。同時進行は計算しません。
- 最後の予定の後の休憩も終了時刻に含まれます。不要なら0分にしてください。
- 移動時間は自動で追加しません。必要な場合は予定として入力してください。
- 日付・タイムゾーン・夏時間は扱わず、開始時刻に経過分数を足します。
- 予定は最大30件。所要時間と休憩はそれぞれ0〜10,080分の整数です。

## 入力内容について

ツールは入力内容を外部へ送信しません。入力内容の自動保存はなく、再読み込みすると消えます。残したい予定表は先にコピーしてください。コピーした内容の送信は行いません。

オンラインで利用する場合、ページ配信サービスには通常のアクセス情報が記録されることがあります。
