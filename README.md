# おわり時間

予定の所要時間と休憩から、全部終わる時刻を計算する無料のミニツールです。終了したい時刻から、必要な開始時刻を逆算することもできます。

## こんなときに

- 午前中の作業が昼休みまでに終わるか確認する
- 終了時刻を決めて、何時から始めればよいか考える
- 勉強、作業、休憩を順番に並べて段取りを組む

## 使い方

1. `owari-jikan/index.html` をブラウザーで開きます。インストールや登録は不要です。
2. 「開始 → 終了を計算」または「終了 → 開始を逆算」を選び、基準の時刻を入力します。
3. 予定名、所要時間、その予定の後に取る休憩を入力します。「上へ」「下へ」で予定を並べ替えられます。
4. 結果と予定表が自動で更新されます。必要ならテキストでコピーして残せます。

最初の入力はサンプルです。「入力をクリア」で消せます。HTMLファイルを保存すれば、外部のスクリプトやフォントを追加せずに開けます。

例：45分の作業、10分の休憩、20分の返信、5分の休憩、40分の会議を11:00までに終えるなら、開始は09:00です。

有効な計算結果がある状態で計算方法を切り替えると、計算済みの開始時刻または終了時刻を引き継ぎます。計算が無効な場合は、以前の入力時刻を保持して注意を表示します。

## 計算の範囲

- 予定は上から順番に実行する想定です。同時進行や、途中の会議などの固定開始時刻は扱いません。
- 現在時刻とは比較しません。「今から間に合うか」の判定ではありません。
- 最後の予定の後の休憩も終了時刻に含めます。不要なら0分にしてください。
- 遅れ、移動、予備時間は自動で追加しません。必要な場合は予定として入力してください。
- 日付・タイムゾーン・夏時間は扱いません。順算の「当日・翌日」は開始日の基準、逆算の「当日・前日」は終了したい日の基準です。
- 予定は最大30件。所要時間と休憩は、それぞれ0〜10,080分の整数です。空欄は0分として扱います。
- 所要時間と休憩が両方0分の行は、予定表とコピー結果から省きます。

## 入力内容について

ツールは入力内容を外部へ送信しません。入力内容の自動保存はなく、再読み込みすると消えます。残したい予定表は先にコピーしてください。コピーした内容の送信は行いません。

オンラインで利用する場合、ページ配信サービスには通常のアクセス情報が記録されることがあります。
