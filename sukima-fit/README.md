# すきまに入る？

会議や休憩を動かさず、分割できない作業1件が入る連続枠を探す無料ツールです。

## 使い方

1. 同じ日の使える時間を `09:00`〜`12:00` のように入力します。
2. 固定予定を1行ずつ `09:40-10:10 打ち合わせ` と入力します。予定がなければ空欄にします。
3. 作業に必要な分数を入力します。必要なら作業前の準備・作業後の片付けも追加します。
4. 自動で表示される候補のうち1枠を選びます。作業の最早開始・最遅開始を確認し、結果をコピーできます。

初期入力は架空のサンプルです。空き時間が40分ずつ3枠なら、合計120分あっても連続45分の作業は入りません。「入る例」では最後の枠が50分となり、45分作業を11:10〜11:15の間に開始できます。

## 計算範囲

- 同日00:00〜24:00、1分単位。24:00は終了だけに使えます。開始と終了が等しい予定は入力エラーです。
- 固定予定は最大30件・入力全体10,000文字以内。予定名は省略可。全角数字・全角コロン、区切りの `-` `–` `—` `~` `〜` `～` を受け付けます。
- 不正な行を黙って読み飛ばしません。エラー時は結果を消し、コピーを無効にします。
- 作業時間は1〜1,440分。前後の時間は各0〜1,440分、空欄は0分です。前後の時間も含めて連続枠を確保します。
- 固定予定の重なりは二重計上せず、注意を表示。開始・終了が接するだけなら重なりません。
- 指定範囲の外にある予定は計算から外し、部分的に外に出る予定は範囲内だけ差し引きます。いずれも注意を表示します。
- 候補枠は作業1件の選択肢です。複数作業の同時割当て・優先順位・日またぎ・日付・時差・夏時間・現在時刻・カレンダー連携は扱いません。
- 移動、予備時間、入力し忘れた予定、実際の所要時間を自動補完しません。ユーザーが入力した条件だけの計算です。

## プライバシーと保存

HTML単体で計算します。外部スクリプト、フォント、分析タグ、データ送信、保存、アカウントはありません。再読込すると架空サンプルへ戻ります。コピーは端末のクリップボードに書き込み、外部へ送信しません。自動コピーが使えない場合は手動選択に切り替えます。

ページ配信サービス（GitHub Pages）には通常のアクセス情報が記録されることがあります。HTMLを保存して開くこともできますが、今回の検証でオフライン動作・全ブラウザーの動作を保証したものではありません。

## 既存ツールとの関係

「おわり時間」は順番に並ぶ作業の終了・開始を計算します。本ツールは会議など固定時刻を動かさず、連続枠を調べます。既存カレンダーや他の空き枠ツールの代替をすべて担うものではありません。
