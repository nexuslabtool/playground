# 文のひと呼吸

日本語の文章から、長い文と読点が多い文を探す無料の補助ツールです。メール、投稿、説明文を読み返す際の目印に使えます。需要や文章改善の効果が実証済みというものではありません。

## 使い方

このフォルダーの index.html をブラウザーで開き、文章を貼り付けて「チェックする」を押します。「元の文を選択」で入力欄の該当箇所へ戻り、手動で編集できます。自動書き換えはしません。

## 判定と限界

- 40・60・80文字の目安を超える文と、読点（、，,）が4個以上の文を表示します。
- URLと改行は文ごとの文字数から除外します。通常文は空行、箇条書きは改行ごとの区切りを選べます。
- 引用内の句点、URLに続く文章やURL末尾の記号などは誤判定する場合があります。英語のピリオドでは区切りません。
- 意味、文法、事実、敬語、文章品質は判定できません。候補ゼロでも読みやすさは保証しません。
- 入力上限は20,000 UTF-16単位です。絵文字などは見た目の文字数と上限カウントが異なることがあります。

入力はブラウザー内で処理し、外部送信・保存はしません。閉じる前に必要な文章を手元へ控えてください。オンライン配信元による通常のアクセス情報記録やブラウザー拡張機能はツールの管理外です。
